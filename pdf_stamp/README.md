# PDF Stamper

A lightweight desktop application for preparing travel and expense claim documentation.

## Features

- Batch PDF processing
- Custom description per PDF
- Digital signature insertion
- Drag and drop support
- Automatic PDF output generation

## Usage

1. Add PDF files
2. Enter a description for each PDF
3. Fill in header information
4. Select signature image
5. Select output folder
6. Click STAMP ALL PDF FILES

## Benefits

- Reduces repetitive manual editing
- Improves consistency
- Saves time when processing multiple receipts
